# Step 1 · 视频切割

把整集正片切成短视频片段。

## 工具与参数

- ffmpeg / ffprobe 路径读 `config.md`
- 切割参数：`-ss <开始> -t <时长> -c copy`（无损快切，不重编码）
- 单集通常 6-7 段，可并行执行

## 指令下发方式

以编号命令清单一次性下发，串行执行；同一模板仅替换集数与保存目录：

```
1. ffmpeg -ss 00:00:00 -t 00:03:00 -i "<源片路径>" -c copy "<输出目录>/S01E01_CUT01.mp4"
2. ffmpeg -ss 00:03:00 -t 00:03:00 -i "<源片路径>" -c copy "<输出目录>/S01E01_CUT02.mp4"
...
```

## 目录约定

`<工作根目录>/<剧名子目录>/<集数>/cut/`

## 完成校验

逐段用 ffprobe 实测时长，输出表格汇报：段号、文件名、时长、大小。切割前先向用户确认源片路径与每段起止时间（或按时长均分）。
