# Step 4 · 词汇抽取（口语学习向剧集启用）

仅在当前剧集档案 `词汇抽取: 开` 时执行。

## 前置分支

先确认本集词汇表状态：

- 已有 Excel → 校验格式后直接使用，跳过抽取
- 没有 → 询问词汇来源（PDF 路径 / 手动提供词表）
- 本集不做词汇 → 整步跳过，step6 渲染时不挂单词视频轨

## PDF 抽取规范（一键脚本）

```bash
python3 scripts/extract_red_words.py <教材.pdf> <输出.xlsx>
```

脚本已实现全部解析规则（跨行合并 / 词性正则 / 特殊符号清洗），运行后自动报告总数 + 未解析清单（`[未解析]` 行原样保留供人工检查，与实战版一致）。要点：

- 抽取对象：PDF 中 `#FF0000` 红色字体的单词
- 输出 Excel：A 列 = 英文，B 列 = 词性 + 中文释义
- 特殊符号保留；无可显示字符时回退为「口」占位
- 用 openpyxl 读写；一次性脚本批处理，完成后报告抽取数量 + 解析失败清单

## 交付

Excel 存至 `<工作根目录>/<剧名子目录>/<集数>/words/words.xlsx`，报告单词总数与失败清单。
