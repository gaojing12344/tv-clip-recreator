# 剧集档案模板

复制本文件为 `shows/<剧名>.md` 并填写。档案只描述「这部剧与通用流程的差异」，通用规范（渲染参数、字幕规范等）在 references/ 里，不要在这里重复。

```markdown
# 剧集档案：<剧名>

- 剧名（中）:
- 剧名（英）:
- 别名: []                # 用户可能的叫法，如「权游」
- 季集编号格式: S01E01     # 或「第1季第1集」
- 定位: 口语学习 | 剧情二创  # 决定词汇/素材步骤开关
- 标签后缀: "#xxx #yyy"

## 功能开关
- 词汇抽取: 开 | 关
- 素材抓取(playphrase): 开 | 关
- 封面圆圈数字: 开 | 关

## 素材来源
- 封面源图: 每次提供 | 固定目录 | 正片截图
- 词汇来源: PDF红色字体 | 手动词表 | 无

## 覆盖通用规范（可选，不填则用 references/ 默认值）
- 视频尺寸:
- 字幕字号:
- 备注:
```
